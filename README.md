CEP Finder

Sobre o Projeto
CEP Finder é uma aplicação web feita para simplificar a busca de endereços e informações de CEP. Desenvolvido com PHP, HTML, CSS e JavaScript, o sistema se comunica com a API pública do ViaCEP para permitir que o usuário consulte um endereço através de um CEP ou, inversamente, encontre o CEP de um endereço fornecido.

Funcionalidades
Consulta de CEP: Insira um CEP e obtenha o endereço completo.

Consulta de Endereço: Informe o endereço (estado, cidade, rua) para encontrar o CEP correspondente.

Requisição de API: Lida com requisições e processa os dados da API ViaCEP para exibir as informações de forma clara e organizada.

Tecnologias Utilizadas
PHP: Linguagem de backend responsável por processar as requisições para a API do ViaCEP.

HTML: Estrutura base da página web.

CSS: Estilização da interface para uma experiência de usuário agradável.

JavaScript: Lógica de frontend para lidar com a interação do usuário e manipular a exibição dos dados.
